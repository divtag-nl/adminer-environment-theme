# adminer-environment-theme

Adminer theme from [OverflowHayden/adminer-theme](https://github.com/OverflowHayden/adminer-theme) with a warning banner per environment (`banner.css`).

To update to the latest upstream theme, run `./build.sh` (or `./build.sh <git ref>`). This regenerates `css/adminer-{staging,acceptance,production}.css`.
